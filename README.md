I'm also into security stuff on the side: labs, networking, and CTF-style machines. I'm still learning, and this profile gets updated whenever I ship something new.

- 🎮 **Roblox & Lua**: scripting, building systems, and figuring out how experiences tick.
- 🔍 **Reverse engineering**: taking things apart (in my own projects and sandboxes) to learn how they work.
- 🧪 **Experience testing**: hunting bugs, edge cases, and weird behavior in games and apps.
- 🛡️ **Pentesting**: lab practice with Wireshark, Burp Suite, and Nmap.
- 🖥️ **Active Directory**: enumeration and attack paths in labs.
- 🔵 **Blue team**: defensive basics and system hardening.
- 🌐 **Networking**: TCP/IP, configuring and troubleshooting setups.
- 💻 **Scripting**: Python and Bash to automate the boring stuff.
- 🗄️ **SQL**: querying and managing data.
